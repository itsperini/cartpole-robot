Modular Experiment Stack

The project now separates physical variation from control-loop behavior. This makes it easier to reproduce old results and to combine stressors intentionally.

For clean reproduction, use robust_scenario = "clean" and control_loop_profile = "none". For hardware-like testing without double-counting delay, prefer hardware_mild plus a control-loop profile. Use hardware_delay plus a profile only as an intentional stress test.

Control-Loop Profiles

Profile Behavior Use it for
none No added timing or actuator effects. Reproducing previous results.
policy_25hz_latency One delayed observation tick and one delayed action tick. First latency sanity check at the current 25 Hz policy rate.
policy_25hz_jitter One-tick latency plus occasional extra one-tick jitter. Testing whether a policy survives variable timing.
policy_25hz_hardware_safe Latency, jitter, action slew-rate limit, deadband, low-pass filtering, and encoder-like quantization. Evaluating existing policies under a gentler hardware-facing loop.
policy_25hz_hardware_delay Two-tick delay plus the same hardware-facing command and sensor effects. Training a delay-history policy that is closer to the eventual hardware loop.

Next Recommended Steps

1. Evaluate before training

Run the existing promoted checkpoints under the new control-loop profiles to see which failure modes are already solved.

2. Train one focused policy

Start with configs/algorithms/td3_realistic_control_loop_history.toml after the evaluation sweep confirms the gap.

3. Delay hardware

Keep the real cart-pole last until the simulator has a credible timing, friction, disturbance, and safety story.

Evaluate existing TD3 history policy

uv run cartpole-robot-robust-eval \
  --algo td3 \
  --model models/best/td3_cartpole_swingup_delay_history_obs4_act3_best_20260629-023430.zip \
  --scenarios hardware_mild \
  --control-loop-profile policy_25hz_hardware_safe \
  --observation-history-steps 4 \
  --action-history-steps 3

Train a realistic loop policy later

uv run cartpole-robot-train \
  --config configs/algorithms/td3_realistic_control_loop_history.toml
